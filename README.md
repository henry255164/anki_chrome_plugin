# Anki Web Clipper

一個 Chrome 瀏覽器擴充功能，讓您可以快速從任何網頁擷取文字，並建立 Anki 單字卡。

## 主要功能 (Features)

- **一鍵開啟介面**: 點擊瀏覽器工具列上的圖示，即可開關擷取器介面。
- **智慧文字選取**: 在網頁上選取任何文字，會自動出現快速新增工具列。
- **輕鬆擷取內容**: 只需點擊一下，即可將選取的文字新增到「問題」或「答案」欄位。
- **直連 Anki**: 使用 AnkiConnect，將製作好的卡片直接新增到您本地的 Anki 桌面應用程式。
- **淺色/深色模式**: 介面會自動適應您的作業系統色彩主題。

## 安裝與設定 (開發用)

1.  確保您已安裝並正在執行 [Anki 桌面版](https://apps.ankiweb.net/)。
2.  在 Anki 中安裝 [AnkiConnect](https://ankiweb.net/shared/info/2055492159) 附加元件。
3.  複製此專案庫：
    ```bash
    git clone https://github.com/your-username/your-repo-name.git
    ```
4.  開啟 Chrome 瀏覽器，前往 `chrome://extensions`。
5.  啟用右上角的「開發人員模式」。
6.  點擊「載入未封裝項目」，並選擇您剛剛複製的專案資料夾。

## 使用方式 (Usage)

1.  點擊 Chrome 工具列中的 **Anki Web Clipper** 圖示以開啟主擷取視窗。
2.  在任何網頁上選取一段文字，旁邊會出現一個包含 'Q' (問題) 和 'A' (答案) 按鈕的小工具列。
3.  點擊 'Q' 或 'A'，將選取的文字加入擷取視窗中對應的欄位。
4.  當您對卡片內容感到滿意時，點擊「Add to Anki」按鈕。
5.  狀態訊息將會提示您卡片是否成功新增。

## 常見問題 (Q&A)

**Q: 按下「Add to Anki」後出現錯誤，或沒有反應怎麼辦？**

**A:** 請確認以下幾點：
1.  **AnkiConnect 是否已安裝並啟用？** 請在 Anki 的「工具」->「附加元件」中確認 `AnkiConnect` 是否存在且未被停用。
2.  **Anki 桌面版是否正在執行？** 本擴充功能需要 Anki 主程式在背景執行才能通訊。
3.  **牌組 (Deck) 與卡片類型 (Note Type) 是否存在？** 本擴充功能預設會將卡片新增至名為 `Default` 的牌組，並使用 `Basic` 的卡片類型。請確保您的 Anki 中存在這兩個項目。
